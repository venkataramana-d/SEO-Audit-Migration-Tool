Recommended: connect with a Service Account (a JSON key file — no API key exists for GSC, and this never expires or needs a browser login).

  1. Google Cloud → your project → IAM & Admin → Service Accounts → Create service account.
  2. Open it → Keys → Add key → Create new key → JSON (a file downloads).
  3. Save that file as service_account.json in the folder {{ sa_path }}.
  4. Copy the service account’s email (…@….iam.gserviceaccount.com) and in Search Console → Settings → Users & permissions → Add user, paste it with Full access.
  5. Reload this page — it’ll show “service account (permanent)”. Verify with python gsc_verify.py.

The OAuth method (python gsc_auth.py) also works and is currently active if no service-account file is present.

PageSpeed Insights API key

Enables real performance & Core Web Vitals data on each URL’s technical audit page.

Get a free key: PageSpeed Insights → Get a Key. It's a plain API key (unlike GSC's OAuth).
  1. In Google Cloud (your “My First Project”), enable the PageSpeed Insights API.
  2. APIs & Services → Credentials → Create credentials → API key.
  3. Paste it above and Save. Then open any URL’s audit page and click Run performance test.
